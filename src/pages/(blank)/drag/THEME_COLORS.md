# 拖拽编辑器主题色规范

## 主题色定义

整个拖拽编辑器使用 **Ant Design 的主题色系统**。

### 组件主题
- **Ant Design 组件**（Button、Card、Drawer 等）：自动使用项目配置的 Ant Design 主题色
- **自定义样式**：通过 CSS 变量引用 Ant Design 主题色，实现主题色统一

> ⚠️ **重要提示**：不要使用 `!important` 覆盖 Ant Design 组件的默认样式。如需修改主题色，请在项目的 Ant Design 主题配置中统一修改。

## CSS 变量使用

Ant Design 5.x 提供了 CSS 变量，可以在自定义样式中直接引用主题色：

### 常用 CSS 变量

```css
/* 主色 */
color: var(--ant-color-primary);

/* 主色浅色背景（悬停） */
background: var(--ant-color-primary-bg-hover);

/* 主色极浅背景 */
background: var(--ant-color-primary-bg);

/* 带降级方案的写法（推荐） */
color: var(--ant-color-primary, #1890ff);
```

### 使用示例

```css
/* ✅ 正确：使用 CSS 变量 */
.my-element {
  border-color: var(--ant-color-primary, #1890ff);
  background: var(--ant-color-primary-bg-hover, #e6f0ff);
}

/* ❌ 避免：硬编码颜色值 */
.my-element {
  border-color: #1890ff;
  background: #e6f0ff;
}
```

### 降级方案

在 CSS 变量不可用时，会自动使用备用值（第二个参数）：
```css
var(--ant-color-primary, #1890ff)
     ↑                    ↑
  CSS 变量（优先）      备用值（降级）
```

## 色彩使用规范

### 主色（Primary Blue）
- **参考色值**：`#1890ff`
- **使用场景**：
  - 画布组件悬停边框
  - 画布组件选中边框
  - 画布组件标签文字
  - 调整大小手柄
  - 分类导航激活背景
  - 空画布悬停边框
  - 拖拽占位符背景
  - 分类导航悬停图标
  - 组件库项悬停边框

### 浅蓝色（Light Blue）
- **色值**：`#e6f0ff`
- **使用场景**：
  - 分类导航悬停背景

- **色值**：`#f0f8ff`
- **使用场景**：
  - 空画布悬停背景

### 蓝色阴影（Blue Shadow）
- **色值**：`rgba(24, 144, 255, 0.2)` 或 `rgba(24, 144, 255, 0.15)`
- **使用场景**：
  - 画布组件悬停阴影
  - 画布组件选中阴影
  - 组件库项悬停阴影

## 中性色系

### 背景色
- **主容器背景**：`#f5f7fa`（浅灰蓝）
- **画布容器背景**：`#f0f2f5`（浅灰）
- **分类导航背景**：`#fafafa`（极浅灰）
- **白色背景**：`#ffffff`

### 边框色
- **默认边框**：`#e8e8e8`
- **空画布边框**：`#d9d9d9`（虚线）

### 文字色
- **深色文字**：`#262626`
- **中灰文字**：`#595959`
- **浅灰文字**：`#999999`

### 功能色
- **删除红色**：`#ff4d4f`（悬停状态）

## 透明度规范

- **拖拽占位符**：`opacity: 0.2`
- **拖拽中的组件**：`opacity: 0.8`
- **调整大小手柄**：`opacity: 0.6`（默认），`opacity: 1`（悬停）

## 组件状态颜色

### 分类导航项
- **默认**：浅灰背景 `#fafafa`，深灰图标 `#595959`
- **悬停**：浅蓝背景 `#e6f0ff`，蓝色图标 `#1890ff`
- **激活**：蓝色背景 `#1890ff`，白色图标和文字 `#ffffff`

### 画布组件
- **默认**：白色背景，浅灰边框 `#e8e8e8`
- **悬停**：蓝色边框 `#1890ff`，蓝色阴影
- **选中**：蓝色边框 `#1890ff`，蓝色外发光阴影

### 组件库项
- **默认**：白色背景，浅灰边框 `#e8e8e8`
- **悬停**：蓝色边框 `#1890ff`，浅蓝阴影

## 设计原则

1. **一致性**：所有交互状态使用统一的蓝色主题
2. **层次性**：通过色彩深浅表达信息层级
3. **可访问性**：保证足够的对比度，确保可读性
4. **渐进式**：通过透明度和阴影表达状态变化
5. **简洁性**：避免过多色彩，保持视觉清晰
6. **主题依赖**：优先使用 Ant Design 主题系统，自定义样式与主题保持一致

## 注意事项

- ✅ **优先使用 Ant Design 组件**，避免过度自定义
- ✅ **使用 CSS 变量**：自定义样式中使用 `var(--ant-color-primary)` 引用主题色
- ✅ **提供降级方案**：使用 `var(--ant-color-primary, #1890ff)` 确保兼容性
- ❌ **避免硬编码**：不要直接写 `#1890ff`，改用 CSS 变量
- ❌ **避免覆盖**：不要使用 `!important` 覆盖 Ant Design 组件样式
- 🔧 **修改主题色**：在项目的 Ant Design 主题配置中统一修改
- 📝 **更新文档**：所有主题色修改应同步更新本文档
- 📐 **遵循规范**：新增组件应遵循现有色彩规范
