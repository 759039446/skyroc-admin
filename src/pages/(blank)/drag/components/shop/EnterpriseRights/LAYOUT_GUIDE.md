## 📏 间距对比

### 小间距 (10px)

```
┌──┬──┬──┬──┬──┬──┐
│  ││  ││  ││  ││  ││  │
└──┴──┴──┴──┴──┴──┘
```
- **视觉感受**：紧凑、密集
- **适用场景**：空间有限、项目很多

### 标准间距 (20px) - 推荐

```
┌──  ──  ──  ──  ──  ──┐
│    │    │    │    │    │
└──  ──  ──  ──  ──  ──┘
```
- **视觉感受**：适中、舒适
- **适用场景**：大多数场景

### 大间距 (40px)

```
┌──      ──      ──      ──┐
│        │        │        │
└──      ──      ──      ──┘
```
- **视觉感受**：宽松、呼吸感强
- **适用场景**：强调重点、高端展示

## 🔍 常见问题

### Q1: 项目数量不是列数的整数倍怎么办？

**A**: 最后一行会自动左对齐，保持相同宽度。

示例（5个项目，3列布局）：
```
┌──────┬──────┬──────┐
│  1   │  2   │  3   │
└──────┴──────┴──────┘
┌──────┬──────┐
│  4   │  5   │
└──────┴──────┘
```

### Q2: 如何让最后一行居中？

**A**: 建议调整列数，使项目数量是列数的整数倍。

### Q3: 不同列数下如何调整组件高度？

**A**: 参考以下公式：
```
行数 = Math.ceil(项目数 / 列数)
建议高度 = 标题高度 + 行数 × (项目高度 + 间距)
```

示例计算：
- 6项 ÷ 2列 = 3行 → 高度约25-30行
- 6项 ÷ 3列 = 2行 → 高度约20-25行
- 6项 ÷ 6列 = 1行 → 高度约12-15行

## 📊 性能建议

### 推荐配置范围

| 项目数量 | 推荐列数 | 不推荐 |
|---------|---------|--------|
| ≤6个    | 2-3列   | ≥6列   |
| 7-12个  | 4-6列   | 2列    |
| ≥12个   | 6-8列   | 2-3列  |

### 性能考虑

- ✅ **少于20个项目**：任意列数都可流畅渲染
- ⚠️ **20-50个项目**：建议6-8列，避免过多行数
- ❌ **超过50个项目**：考虑分页或虚拟滚动

## 🎁 设计技巧

### 1. 保持视觉平衡
- 偶数列（2、4、6、8）更对称
- 3列和6列有特殊的美感

### 2. 间距黄金比例
```
项目宽度 : 间距 ≈ 10 : 1
例如：200px宽度 → 20px间距
```

### 3. 避免文字溢出
- 标题：≤6个字
- 描述：≤10个字
- 使用省略号处理超长文本

### 4. 颜色搭配
- 图标色：品牌主色
- 背景色：浅灰或白色
- 悬停色：更深的灰色
