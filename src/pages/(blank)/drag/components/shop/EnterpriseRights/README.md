# 企业权益组件

## 📋 组件说明

企业权益组件用于展示企业会员的专属权益和常用功能，采用网格布局，**真正的动态自适应系统**，无需配置即可完美适配任意尺寸。

## 🎯 功能特性

### 1. **真正的动态自适应** ⭐⭐⭐ 革命性升级
- ✅ 实时读取容器的真实宽度和高度
- ✅ 根据实际尺寸动态计算所有元素大小
- ✅ 支持任意尺寸的容器，无缝适配
- ✅ 使用 ResizeObserver 实时响应尺寸变化
- ✅ 不再依赖写死的配置，完全自动化

### 2. **智能计算系统** ⭐⭐⭐ 核心技术
- ✅ 图标大小 = 可用空间的 40%（20-60px）
- ✅ 标题大小 = 项目宽度的 10%（12-22px）
- ✅ 描述大小 = 标题的 75%（10px起）
- ✅ 内边距 = 可用空间的 10%（8-24px）
- ✅ 所有尺寸基于比例，自动保持美观

### 3. **智能显示策略** ⭐⭐ 
- ✅ 项目宽度 ≥ 120px：显示完整信息（图标+标题+描述）
- ✅ 项目宽度 < 120px：自动隐藏描述，只显示图标和标题
- ✅ 根据实际空间自动决定显示内容
- ✅ 无需手动配置，完全智能化

### 4. **动态网格布局**
- ✅ 支持配置每行显示的列数（2-8列）
- ✅ 自动响应式布局，平均分配宽度
- ✅ 可自定义项目间距

### 4. **可配置内容**
- ✅ 自定义图标、标题、描述
- ✅ 支持多种内置图标
- ✅ 文本配置简单快捷

### 5. **视觉效果**
- ✅ 卡片式设计
- ✅ 悬停动画效果
- ✅ 可自定义颜色主题

## 🎨 配置项

### 每行列数 (columnsPerRow)
控制每行显示的项目数量，默认为 6 列。

**可选值**：
- `2` - 每行2列（大图标展示）
- `3` - 每行3列（常用布局）
- `4` - 每行4列（常用布局）
- `5` - 每行5列（紧凑布局）
- `6` - 每行6列（默认，标准紧凑）
- `8` - 每行8列（极度紧凑）

**动态适应**：
- ✅ 所有元素尺寸根据实际容器大小自动计算
- ✅ 列数越少，单个项目越大，元素也越大
- ✅ 列数越多，单个项目越小，元素也越小
- ✅ 当项目宽度 < 120px 时，自动隐藏描述
- ✅ 无论什么列数，都保持最佳视觉比例

**示例效果**：

```

┌─────────────┬─────────────┐
│ 企业专享价  │ 企业达量返  │

┌─────────────┬─────────────┐
│ 企业团购    │ 工作台      │
└─────────────┴─────────────┘

每行6列（默认）：
┌────┬────┬────┬────┬────┬────┐
│专享│达量│团购│工台│订单│开票│
└────┴────┴────┴────┴────┴────┘
```

**范围**：0-50px

### 项目高度 (itemHeight) ⭐ 新功能
控制每个项目卡片的高度。

**输入方式**：
- 数字输入框，支持50-300px范围
- 留空则自动适应（推荐）
- 自定义输入任意高度值

**自动适应规则**：
- 留空时，根据列数自动计算最佳高度
- 2列：160px，3列：140px，4列：130px，5列：120px，6列：100px，8列：90px

**推荐高度**：
- 90px - 极紧凑，适合8列布局
- 100px - 紧凑，适合6列布局
- 120px - 标准，适合4-5列布局
- 140px - 舒适，适合3列布局
- 160px - 宽松，适合2列布局
- 180px+ - 超大，适合特殊展示

**使用说明**：
- 留空或不设置时，组件会根据列数自动选择最佳高度
- 输入具体数值时，所有项目统一使用该高度
- 内容自动垂直居中对齐，确保视觉平衡

**高度对照表**：

| 3列  | 140px   | 140-160px   | 舒适美观 |

## 🔬 动态计算原理

### 核心算法

组件使用智能算法根据实际容器尺寸动态计算所有元素大小，确保在任何尺寸下都保持最佳视觉效果。

### 计算流程

#### 1. 获取容器尺寸
```javascript
// 使用 ResizeObserver 实时监听
containerWidth = 实际宽度;
containerHeight = 实际高度;
```

#### 2. 计算项目尺寸
```javascript
// 每个项目的可用宽度
itemWidth = (containerWidth - 所有间距) / 列数;

// 每个项目的高度
if (手动设置) {
  itemHeight = 设置值;
} else {
  rows = Math.ceil(项目数 / 列数);
  itemHeight = (containerHeight - 所有间距) / rows;
}
```

#### 3. 计算元素尺寸（基于比例）
```javascript
baseSize = Math.min(itemWidth, itemHeight);

// 图标 = 基准的 40%
iconSize = baseSize × 0.4 (20-60px);

// 标题 = 宽度的 10%
titleSize = itemWidth × 0.1 (12-22px);

// 描述 = 标题的 75%
descSize = titleSize × 0.75 (10px+);

// 内边距 = 基准的 10%
padding = baseSize × 0.1 (8-24px);
```

#### 4. 智能显示判断
```javascript
showDesc = itemWidth >= 120px;
```

### 尺寸范围

| 元素 | 计算方式 | 最小 | 最大 |
|------|---------|-----|-----|
| 图标 | baseSize × 0.4 | 20px | 60px |
| 标题 | itemWidth × 0.1 | 12px | 22px |
| 描述 | titleSize × 0.75 | 10px | - |
| 内边距 | baseSize × 0.1 | 8px | 24px |
| 内部间距 | baseSize × 0.07 | 6px | 14px |

### 响应式行为

```
容器变大 → 项目变大 → 元素按比例变大
容器变小 → 项目变小 → 元素按比例变小  
列数增加 → 项目变小 → 可能隐藏描述
列数减少 → 项目变大 → 自动显示描述
```

## 布局计算

### 网格布局原理

组件使用 CSS Grid 布局：
```css
display: grid;
grid-template-columns: repeat(columnsPerRow, 1fr);
gap: gap px;
```

### 自动计算

每个项目的宽度自动计算：
```
项目宽度 = (容器宽度 - (列数-1) × 间距) / 列数
```

**示例计算**（容器宽度 1200px）：

| 列数 | 间距 | 项目宽度 |
|------|------|---------|
| 2列  | 20px | 590px   |
| 3列  | 20px | 386px   |
| 4列  | 20px | 285px   |
| 6列  | 20px | 183px   |
| 8列  | 20px | 132px   |

## 💡 使用建议

### 1. 根据项目数量选择列数

| 项目总数 | 推荐列数 | 说明 |
|---------|---------|------|
| 2-4个   | 2-4列   | 大图标展示，视觉冲击力强 |
| 6个     | 3列或6列 | 3列2行或6列1行 |
| 8个     | 4列     | 4列2行，布局均衡 |

### 2. 根据屏幕尺寸调整

- **大屏显示器**：可使用6-8列，充分利用空间
- **普通显示器**：推荐4-6列，保持清晰可读
- **移动端**：建议2-3列，便于点击

### 3. 间距建议

- **紧凑风格**：10-15px
- **标准风格**：20-25px（推荐）
- **宽松风格**：30-40px

## 🔧 调整组件高度

根据列数和项目总数，组件高度会自动变化。

**计算公式**：
```
行数 = Math.ceil(项目总数 / 每行列数)
所需高度 ≈ 标题高度 + (行数 × 项目高度) + ((行数-1) × 间距) + 内边距
```

**高度建议**（heightRows）：

| 布局 | 项目数 | 建议高度 |
|------|--------|---------|
| 2列  | 6项    | 25-30行 |
| 3列  | 6项    | 20-25行 |
| 4列  | 8项    | 20-25行 |
| 6列  | 6项    | 15-20行 |
| 8列  | 8项    | 12-15行 |

## 🎯 最佳实践

### 1. 保持视觉平衡
- 每行项目数量应为偶数（2、4、6、8）
- 避免最后一行只有1个项目

### 2. 内容精简
- 标题控制在5个字以内
- 描述控制在8个字以内
- 避免文字换行

### 3. 图标选择
- 选择语义清晰的图标
- 保持图标风格统一
- 图标颜色与品牌色一致

### 4. 间距设置
- 项目较大时使用大间距（30-40px）
- 项目较小时使用小间距（10-15px）
- 保持整体协调
