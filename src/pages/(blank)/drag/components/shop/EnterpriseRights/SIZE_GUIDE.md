# 企业权益组件 - 尺寸自适应指南

## 📐 动态尺寸原理

企业权益组件会根据**每行列数**自动调整图标、文字和内边距的大小，确保在不同布局下都有最佳的视觉效果。

### 核心理念

```
列数越多 → 项目越小 → 图标和文字应该更小
列数越少 → 项目越大 → 图标和文字应该更大
```

## 🎯 智能显示策略

### 自动显示/隐藏规则

组件会根据列数自动决定显示哪些元素，优化空间利用和视觉效果：

| 列数 | 图标 | 标题 | 描述 | 策略说明 |
|------|------|------|------|---------|
| **2-5列** | ✅ | ✅ | ✅ | 空间充足，显示所有元素 |
| **6列** | ✅ | ✅ | ❌ | 空间紧凑，隐藏描述 |
| **8列** | ✅ | ✅ | ❌ | 空间极限，隐藏描述 |

### 为什么6列和8列隐藏描述？

**空间分析**：
```
2列：每个项目宽度约 45-50%   → 空间充足 ✅
4列：每个项目宽度约 22-25%   → 空间适中 ✅
6列：每个项目宽度约 14-16%   → 空间紧张 ⚠️
8列：每个项目宽度约 10-12%   → 空间极限 ⚠️
```

**显示效果对比**：

#### 6列显示描述（不推荐）
```
┌──────┐
│  👑  │  ← 图标太小
│专享价│  ← 标题拥挤
│会员价│  ← 描述拥挤
└──────┘
```

#### 6列隐藏描述（推荐）✅
```
┌──────┐
│  👑  │  ← 图标适中
│专享价│  ← 标题清晰
│      │  ← 留白舒适
└──────┘
```

### 显示优先级

```
优先级从高到低：
1. 图标 (必须显示) - 最直观的识别元素
2. 标题 (优先显示) - 核心信息
3. 描述 (可选显示) - 辅助信息，空间不足时隐藏
```

### 自定义显示策略

如需修改显示策略，编辑 `getSizeConfig` 函数：

  icon: 28,

},

## 📊 尺寸计算规则

### 图标尺寸公式

```javascript
图标大小 = 基准尺寸(60px) - (列数 × 缩放因子)

示例：
- 2列：60 - (2 × 2) = 56px
- 4列：60 - (4 × 5.5) ≈ 38px
- 6列：60 - (6 × 5) = 30px
- 8列：60 - (8 × 4.25) ≈ 26px
```

### 标题尺寸公式

```javascript
标题大小 = 基准尺寸(22px) - (列数 × 缩放因子)

示例：
- 2列：22 - (2 × 1) = 20px
- 4列：22 - (4 × 1.5) = 16px
- 6列：22 - (6 × 1.33) ≈ 14px
- 8列：22 - (8 × 1.13) ≈ 13px
```

### 内边距公式

```javascript
内边距 = 基准尺寸(24px) - (列数 × 缩放因子)

示例：
- 2列：24 - (2 × 2) = 20px
- 4列：24 - (4 × 2.25) ≈ 15px
- 6列：24 - (6 × 2) = 12px
- 8列：24 - (8 × 1.75) = 10px
```

## 💡 设计建议

### 1. 文字长度建议

根据列数控制文字长度：

| 列数 | 标题最大字数 | 描述最大字数 | 原因 |
|------|------------|------------|------|
| 2列  | 8字以内    | 12字以内   | 空间充足 |
| 3列  | 6字以内    | 10字以内   | 适中 |
| 4列  | 5字以内    | 8字以内    | 标准 |
| 6列  | 4字以内    | 6字以内    | 紧凑 |
| 8列  | 3字以内    | 5字以内    | 极限 |

**示例**：
- ✅ 2列："企业专享价" (5字) + "会员专属价格" (6字)
- ✅ 6列："专享价" (3字) + "会员价" (3字)
- ❌ 8列："企业专享价格优惠" (8字) - 太长！

### 2. 行高设置

```css
标题：line-height: 1.2  /* 紧凑清晰 */
描述：line-height: 1.3  /* 稍微宽松 */
```

### 3. 图标选择建议

不同列数下的图标选择：

- **2-3列**：可使用复杂图标，细节清晰
- **4-5列**：使用中等复杂度图标
- **6-8列**：使用简洁图标，避免细节过多

## 🔧 自定义尺寸

### 代码实现

```typescript
const getSizeConfig = (columns: number) => {
  const sizeMap = {
    2: { icon: 56, title: 20, desc: 14, padding: 20, gap: 12 },
    3: { icon: 44, title: 18, desc: 13, padding: 18, gap: 12 },
    4: { icon: 38, title: 16, desc: 12, padding: 15, gap: 10 },
    5: { icon: 34, title: 15, desc: 12, padding: 12, gap: 10 },
    6: { icon: 30, title: 14, desc: 11, padding: 12, gap: 8 },
    8: { icon: 26, title: 13, desc: 10, padding: 10, gap: 8 },
  };
  return sizeMap[columns] || sizeMap[6];
};
```

### 如何修改

如果需要自定义尺寸，编辑 `index.tsx` 中的 `getSizeConfig` 函数：

```typescript
// 示例：让2列布局的图标更大
2: { icon: 64, title: 22, desc: 16, padding: 24, gap: 14 },
```

## ⚠️ 注意事项

### 1. 文字截断

列数越多，空间越小，注意避免文字溢出：

```css
/* 建议添加文字省略 */
overflow: hidden;
text-overflow: ellipsis;
white-space: nowrap;
```

### 2. 图标清晰度

- ✅ 矢量图标（SVG、IconFont）- 任何尺寸都清晰
- ⚠️ 位图图标 - 缩小可能模糊

### 3. 最小尺寸限制

建议的最小尺寸：
- 图标：≥24px
- 标题：≥12px
- 描述：≥10px

当前最小配置（8列）符合标准 ✅

## 📈 性能优化

### CSS 性能

动态尺寸使用内联样式，性能优秀：

```typescript
<div style={{ fontSize: `${sizeConfig.icon}px` }}>
```

优势：
- ✅ 无需额外 CSS 类
- ✅ 直接应用，无级联
- ✅ 便于动态计算
