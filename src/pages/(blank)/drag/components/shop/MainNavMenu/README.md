## 📊 数据结构

### categories.json

三级分类数据结构：

```json
[
  {
    "name": "一级分类名称",
    "subCategories": [
      {
        "name": "二级分类名称",
        "items": [
          "三级分类1",
          "三级分类2",
          "三级分类3"
        ]
      }
    ]
  }
]
```

### 数据说明

- **一级分类**：顶级分类，显示在左侧主菜单
- **二级分类**：中级分类，在浮窗中以粗体标题显示
- **三级分类**：最细分类，在浮窗中以标签形式显示

## 🔧 如何修改分类数据

### 1. 添加新的一级分类

在 `categories.json` 数组末尾添加：

```json
{
  "name": "新分类名称",
  "subCategories": [
    {
      "name": "子分类1",
      "items": ["商品1", "商品2", "商品3"]
    }
  ]
}
```

### 2. 添加二级分类

在对应一级分类的 `subCategories` 数组中添加：

```json
{
  "name": "新二级分类",
  "items": ["商品1", "商品2", "商品3"]
}
```

### 3. 添加三级分类

在对应二级分类的 `items` 数组中添加：

```json
"items": ["现有商品1", "现有商品2", "新添加的商品"]
```

## 💡 最佳实践

### 1. 命名规范
- 使用简洁明确的分类名称
- 避免过长的名称（建议不超过10个字）
- 使用 `/` 分隔相关分类

### 2. 数据量建议
- 一级分类：5-10 个
- 二级分类：每个一级分类 4-8 个
- 三级分类：每个二级分类 6-10 个

### 3. JSON 格式
- 确保 JSON 格式正确（使用 JSON 验证工具）
- 保持适当的缩进（2 或 4 个空格）
- 中文字符无需转义

## ⚠️ 注意事项

1. **JSON 语法**
   - 最后一个元素后不要加逗号
   - 字符串必须使用双引号
   - 数组和对象的括号要配对

2. **数据完整性**
   - 每个一级分类必须有 `name` 和 `subCategories`
   - 每个二级分类必须有 `name` 和 `items`
   - `items` 必须是字符串数组

3. **性能考虑**
   - 总分类数量建议不超过 500 个
   - 单个二级分类的三级分类数量建议不超过 20 个

## 🎨 样式文件

### styles.css

包含主导航菜单的所有滚动条样式：

- **主分类列表滚动条**：8px 宽度，渐变效果
- **子菜单滚动条**：10px 宽度，渐变效果
- **悬停效果**：主题色渐变 + 发光阴影
- **按压效果**：纯主题色反馈

**使用方式**：
```typescript
import './styles.css';
```

**修改样式**：
直接编辑 `styles.css` 文件即可自定义滚动条外观。

详细的滚动条样式说明请查看 `SCROLLBAR.md`。
