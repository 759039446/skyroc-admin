# 浮动工具栏使用指南

## 功能概述

浮动工具栏提供了快捷的 DSL 数据管理功能，包括导入、导出和编辑画布组件的 JSON 数据。

## 工具栏位置

- **固定位置**：画布右下角（距离右侧和底部各 20px）
- **始终可见**：工具栏固定在页面右下角，不可移动

## 功能按钮

### 1. 📥 导入 (ImportOutlined)

**功能**：导入 DSL JSON 文件到画布

**使用方法**：
1. 点击导入按钮
2. 在文件选择对话框中选择 `.json` 文件
3. 文件内容会自动解析并替换当前画布组件

**JSON 格式要求**：
```json
[
  {
    "i": "unique-id",
    "type": "component-type",
    "x": 0,
    "y": 0,
    "w": 10,
    "h": 8,
    "props": {
      // 组件属性
    }
  }
]
```

**提示**：
- JSON 必须是组件数组格式
- 导入会替换当前所有画布组件
- 导入操作会记录到历史，可以撤回

### 2. 📤 导出 (ExportOutlined)

**功能**：导出当前画布所有组件为 JSON 文件

**使用方法**：
1. 点击导出按钮
2. 浏览器会自动下载 JSON 文件

**文件命名**：
- 格式：`canvas-{timestamp}.json`
- 示例：`canvas-1701234567890.json`

**用途**：
- 保存当前画布配置
- 备份组件布局
- 在不同环境间迁移配置

### 3. ✏️ 编辑 (EditOutlined)

**功能**：打开 JSON 编辑器弹窗，直接编辑画布数据

**使用方法**：
1. 点击编辑按钮
2. 在弹出的编辑器中修改 JSON
3. 点击"格式化"按钮可以格式化 JSON
4. 点击"应用"按钮将修改应用到画布

**编辑器功能**：
- **实时编辑**：直接修改 JSON 文本
- **格式化**：一键格式化 JSON，便于阅读
- **语法检查**：实时检测 JSON 语法错误
- **错误提示**：显示具体的错误信息
- **应用**：将修改应用到画布
- **取消**：放弃修改，关闭编辑器

## 使用场景

### 场景 1：保存和加载配置

1. 设计完成后点击"导出"保存配置
2. 需要时点击"导入"加载之前保存的配置

### 场景 2：批量修改组件

1. 点击"编辑"打开 JSON 编辑器
2. 使用文本编辑器的查找替换功能批量修改
3. 点击"应用"更新画布

### 场景 3：复制配置到其他环境

1. 在源环境点击"导出"
2. 将 JSON 文件发送到目标环境
3. 在目标环境点击"导入"加载配置

### 场景 4：精确调整布局

1. 点击"编辑"打开 JSON 编辑器
2. 精确修改组件的 `x`、`y`、`w`、`h` 值
3. 点击"应用"查看效果

### 场景 5：快速访问

工具栏固定在右下角，无论画布如何滚动，都可以快速访问导入/导出/编辑功能

## 注意事项

1. **数据格式**：导入的 JSON 必须是有效的组件数组
2. **数据替换**：导入会完全替换当前画布，建议先导出备份
3. **语法检查**：应用前请确保 JSON 语法正确
4. **历史记录**：所有操作都会记录到历史，可以使用撤回/恢复功能
5. **固定位置**：工具栏固定在右下角，始终可见

## 快捷提示

- **工具栏位置**：工具栏固定在画布右下角，始终可见
- **格式化**：编辑 JSON 前建议先点击"格式化"，便于阅读和编辑
- **错误修复**：如果应用 JSON 失败，检查错误提示信息，修正后重试

## 技术说明

- **固定定位**：使用 CSS `position: fixed` 固定在右下角
- **文件处理**：使用 FileReader API 读取文件
- **JSON 处理**：使用原生 JSON.parse/stringify
- **下载实现**：使用 Blob 和 URL.createObjectURL
- **主题色**：使用 Ant Design CSS 变量，自动跟随项目主题
