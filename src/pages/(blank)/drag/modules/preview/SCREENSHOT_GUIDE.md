# 预览截图功能说明

## 📸 功能概述

预览窗口现在支持一键截图功能，可以将整个画布内容导出为高清图片。

## 🎯 功能特性

### 1. **一键截图**
- ✅ 点击标题栏的"截图"按钮即可截图
- ✅ 自动将整个画布内容转换为图片
- ✅ 自动下载到本地

### 2. **高清输出**
- ✅ 使用 2倍缩放，确保图片清晰度
- ✅ PNG 格式，支持透明背景（如需要）
- ✅ 完整保留所有样式和布局

### 3. **智能命名**
- ✅ 自动生成文件名：`页面截图_时间戳.png`
- ✅ 避免文件名冲突
- ✅ 方便管理和查找

## 🔧 技术实现

### 核心技术栈

- **html2canvas**: 将 DOM 元素转换为 Canvas
- **Canvas API**: 将 Canvas 导出为图片
- **Blob API**: 创建下载链接

### 实现流程

```typescript
1. 点击截图按钮
   ↓
2. 显示加载提示
   ↓
3. html2canvas 将 DOM 转换为 Canvas
   ↓
4. Canvas 转换为 Blob
   ↓
5. 创建下载链接并触发下载
   ↓
6. 清理资源，显示成功提示
```

## 📖 使用方法

### 步骤1：打开预览窗口
在拖拽编辑器中点击"预览"按钮

### 步骤2：点击截图按钮
在预览窗口标题栏，点击 📷 "截图" 按钮

### 步骤3：等待生成
系统会显示"正在生成截图..."的提示

### 步骤4：自动下载
图片生成后会自动下载到浏览器的默认下载目录

## ⚙️ 配置选项

### html2canvas 配置

```typescript
{
  backgroundColor: '#ffffff',  // 背景颜色
  scale: 2,                    // 缩放比例（2倍提高清晰度）
  useCORS: true,              // 允许跨域图片
  logging: false,             // 关闭日志
  windowWidth: scrollWidth,   // 使用滚动宽度
  windowHeight: scrollHeight, // 使用滚动高度
}
```

### 可自定义项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| **backgroundColor** | 背景颜色 | #ffffff |
| **scale** | 清晰度缩放 | 2 |
| **format** | 图片格式 | image/png |
| **filename** | 文件名模板 | 页面截图_{timestamp}.png |

## 🐛 常见问题

### Q1: 截图不完整？
**A**: 确保预览窗口已经完全加载所有内容，等待所有组件渲染完成后再截图。

### Q2: 截图模糊？
**A**: 当前使用 2倍缩放（scale: 2），如需更高清晰度可以调整 scale 值。

### Q3: 跨域图片不显示？
**A**: 已经开启了 useCORS 选项，如果图片服务器不支持 CORS，需要配置服务器允许跨域。

### Q4: 截图文件太大？
**A**: 可以调整 scale 参数或使用 JPEG 格式（质量稍低但文件更小）。

### Q5: 截图失败？
**A**: 检查浏览器控制台错误信息，可能是内存不足或 DOM 结构过于复杂。

## 🔍 技术细节

### 性能优化

1. **按需加载**: html2canvas 只在点击截图时加载
2. **内存管理**: 及时清理 Blob URL，避免内存泄漏
3. **错误处理**: 完善的错误捕获和提示

### 兼容性

- ✅ Chrome/Edge 90+
- ✅ Firefox 88+
- ✅ Safari 14+
- ⚠️ IE 不支持

### 限制说明

1. **Canvas 限制**: 某些 CSS 特性可能无法完美转换
2. **字体限制**: 需要字体文件已经加载完成
3. **图片限制**: 跨域图片需要服务器支持 CORS
4. **尺寸限制**: 超大页面可能导致浏览器内存不足
